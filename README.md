# Ultimate MERN Stack Beginner Course

Welcome to the ultimate package for learning MERN Stack (MongoDB, Express, React, Node.js) development! This repository contains 20 projects curated specifically for beginners, progressing from absolute basics to advanced full-stack architectures.

Each project is designed to teach you a core concept in modern web development.

## How to use this repository

1. **Follow the Levels:** Start from Level 1 and move your way down. Each level builds upon the concepts learned in the previous one.
2. **Read the README:** Each project directory has its own `README.md` file detailing the concepts, setup instructions, and code explanation.
3. **Do the Assignments:** At the end of every project's README, you will find assignments. **Do not skip these!** They are crucial for solidifying your understanding.
4. **Read the Comments:** The code files are heavily commented to explain *why* something is done, not just *what* is done.

## The Curriculum

### Level 1: Node.js & Express Basics
Focus: Server setup, routing, and basic API endpoints.
- [01-Hello-API](./01-Hello-API) - A basic Express server returning JSON responses.
- [02-Calculator-API](./02-Calculator-API) - An API taking numbers via query params and returning calculations.
- [03-File-Manager](./03-File-Manager) - An API to read, write, and list files on the server using Node's `fs` module.

### Level 2: Databases with MongoDB & Mongoose
Focus: Data modeling, CRUD operations, and connecting to a database.
- [04-Book-Library-API](./04-Book-Library-API) - RESTful API for Books.
- [05-User-Auth-API](./05-User-Auth-API) - Registration/Login system with JWT & bcrypt.
- [06-URL-Shortener](./06-URL-Shortener) - Create short aliases for long URLs.

### Level 3: React Fundamentals
Focus: UI building, components, state, and props (Frontend only).
- [07-Counter-App](./07-Counter-App) - Simple React app introducing `useState`.
- [08-Todo-UI](./08-Todo-UI) - Frontend Todo list introducing component structuring and array mapping.
- [09-Weather-App](./09-Weather-App) - Fetching and displaying data from a public API (`useEffect`).

### Level 4: Full-Stack Integration (MERN)
Focus: Connecting the React frontend to the Node/Express backend.
- [10-MERN-Todo](./10-MERN-Todo) - Fully persistent Todo application.
- [11-Note-Taker](./11-Note-Taker) - Full-stack app to write, edit, and categorize markdown notes.
- [12-Expense-Tracker](./12-Expense-Tracker) - Log income and expenses with simple statistics.

### Level 5: Intermediate MERN Applications
Focus: Complex state management, relationships in MongoDB, and advanced UI.
- [13-Recipe-Book](./13-Recipe-Book) - Share recipes with image uploading (Multer).
- [14-Tech-Blog](./14-Tech-Blog) - Blogging platform with relational data (Users, Posts, Comments).
- [15-Realtime-Chat](./15-Realtime-Chat) - Simple chat room using `Socket.io`.
- [16-Movie-Review-App](./16-Movie-Review-App) - Browse movies and leave ratings/reviews.

### Level 6: Advanced MERN Architectures
Focus: Production-ready features, payments, and complex dashboards.
- [17-Task-Manager](./17-Task-Manager) - Kanban-style board (like Trello).
- [18-Job-Board](./18-Job-Board) - Role-based access control (Admin vs User).
- [19-E-Commerce-Store](./19-E-Commerce-Store) - Shopping cart with mock checkout integration.
- [20-Portfolio-Generator](./20-Portfolio-Generator) - Dynamic app generating customizable portfolio websites.
